# cpp07 - 42 School C++ Module 07

This repository contains solutions for the C++ Module 07 at 42 School, focusing on mastering templates in C++98.


## 🧠 Objectives

- **Exercise 00:** Implement template functions `swap`, `min`, and `max` to demonstrate basic template usage.
- **Exercise 01:** Develop template functions to handle generic data types.
- **Exercise 02:** Create template classes to understand class templates.

## ⚙️ Requirements

- C++98 compliant compiler (e.g., `g++`)
- Make utility

## 🚀 Usage

   ```bash
   git clone https://github.com/amakarem/cpp07.git
   cd cpp07```
